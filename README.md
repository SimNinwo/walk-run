# Splits

A focused, offline-capable walk/run interval timer built as a Progressive Web App.

## Run locally

Serve this directory over HTTP (for example, with any local static-file server), then open `index.html`. Service workers and install support are not available from a `file://` URL.

## Features

- Configurable warm-up, run, walk, round, and cool-down intervals
- Presets and session history saved in browser storage
- Audio and vibration cues where supported
- Installable, offline-ready app shell
